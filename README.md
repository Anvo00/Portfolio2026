# Vito Giacobelli — Portfolio

Single-page portfolio for Vito Giacobelli (MA Graphic Design, Accademia
Italiana, Firenze). Built with **Astro**, self-hosted **Gobold** + **Sora**
fonts, no runtime JS framework.

Sections: **Hero → About → Projects → Footer**, behind a logo intro.

## Commands
| Command | Action |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Dev server at `http://localhost:4321` |
| `npm run build` | Static build into `dist/` |
| `npm run preview` | Preview the production build |
